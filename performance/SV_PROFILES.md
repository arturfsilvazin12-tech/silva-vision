# ⚡🇧🇷 PERFIS DE PERFORMANCE

## 🟢 Performance
Para PCs onde FPS é prioridade.

Core enxuto, bloom desligado por padrão e efeitos experimentais desativados.

## ⚖️ Balanced
Perfil recomendado para começar os testes.

Equilibra aparência e custo.

## 🔵 Quality
Prioriza qualidade visual, aceitando custo maior.

## 🟣 Ultra
Todos os módulos compatíveis de qualidade podem ser avaliados.

## 🎬 Cinematic
Perfil visual para screenshots/cenas, não pensado como preset competitivo.

## Regra

Nenhum perfil recebe promessa de FPS antes de benchmark real.
