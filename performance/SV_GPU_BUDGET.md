# ⚡ SV GPU Budget

## Objetivo

Nenhum efeito entra no perfil principal apenas por parecer bonito em screenshot.

Cada efeito será medido quando o usuário puder testar.

| Classe | Regra |
|---|---|
| 🟢 A | custo mínimo / alto benefício |
| 🟢 B | custo baixo |
| 🟡 C | custo moderado |
| 🟠 D | custo alto |
| 🔴 E | experimental / pesado |

## Métricas

- FPS médio
- 1% low
- frame time
- GPU utilization
- VRAM
- custo aproximado do efeito

## Perfis futuros

### 🟢 Performance
Só efeitos A/B.

### ⭐ Balanced
A/B + alguns C.

### 🎬 Quality
A/B/C.

### 🔥 Ultra
Pode usar D.

### 🧪 Experimental
Pode usar E.

## Regra de ouro

Não prometer aumento de FPS. O objetivo é controlar o custo visual do Silva Vision e permitir rollback rápido.
