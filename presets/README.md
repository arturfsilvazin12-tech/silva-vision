# 🎨 Presets Silva Vision

Esta pasta será usada para os presets oficiais.

## ⭐ Planejados

- `SV_Neutral` — correção natural e referência A/B.
- `SV_Balanced` — equilíbrio entre qualidade e desempenho.
- `SV_Cinematic` — imagem mais cinematográfica.
- `SV_Night` — foco em iluminação urbana e noite.
- `SV_Rain` — foco em chuva e superfícies molhadas.
- `SV_Performance` — menor custo possível.

⚠️ Os presets ainda não são considerados releases finais até serem testados no jogo.

## 🛡️ Regra

Cada preset deve declarar dependências, versão, efeitos utilizados, riscos conhecidos e método de restauração.
