## 🧪 Regra

Esta tabela é uma matriz de planejamento. Um `🟢` significa que o preset foi criado como base para aquela finalidade; não significa que a funcionalidade completa já esteja implementada.

## 🛡️ Por que separar presets?

Uma única configuração não consegue otimizar simultaneamente uma cena diurna, uma noite urbana, uma chuva intensa e uma captura cinematográfica. Separar perfis permite evolução incremental e facilita diagnóstico.
