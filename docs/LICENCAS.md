# 📜 Silva Vision — Licenças e Créditos

## 🟢 Regra

O Silva Vision terá código, configurações e documentação próprios sempre que possível. Referências públicas servem para pesquisa e engenharia, não para copiar trabalho de terceiros.

## 🔎 Projetos pesquisados

- `crosire/reshade-shaders` — coleção pública de shaders ReShade;
- `prod80/prod80-ReShade-Repository` — efeitos de cor/pós-processamento; o repositório declara MIT;
- `Jarrrk/FiveM-VisualSettings` — referência de streaming de visualsettings em FiveM;
- `johnatha3434535/fivem-Visual-Settings` — inventário público de parâmetros;
- `IDKFORCE/fs-graphics` — referência comunitária de escopo de melhorias e problemas recorrentes.

## ⚠️ Importante

Licença de um projeto não significa que todos os arquivos encontrados na internet possam ser redistribuídos. Antes de incluir qualquer shader, textura, modelo, preset ou asset de terceiros:

1. conferir licença do arquivo/projeto;
2. verificar se redistribuição é permitida;
3. manter créditos exigidos;
4. não incluir conteúdo proprietário sem autorização.

## 🚫 Não redistribuir

O projeto não deve incorporar arquivos proprietários de packs comerciais apenas porque foram usados como inspiração visual.

## 🧾 Créditos

O arquivo será atualizado conforme componentes de terceiros forem oficialmente incorporados com licença compatível.
