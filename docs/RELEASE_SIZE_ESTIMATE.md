# 📦🇧🇷 Estimativa de tamanho do Silva Vision

O tamanho final ainda não pode ser conhecido com precisão porque depende dos assets aprovados após os testes.

| Edição | Conteúdo | Estimativa |
|---|---|---:|
| Lite | ReShade + presets + configs | 10–50 MB |
| Core | Lite + módulos World/configuração | 50–250 MB |
| Full | Core + texturas/efeitos próprios | 250 MB–1 GB |
| Asset Heavy | grandes packs de texturas/ambiente | 1–5+ GB |

## 🎯 Meta

A versão padrão deve priorizar shaders, configurações e assets próprios compactados. Não vamos adicionar gigabytes apenas para aumentar o tamanho do mod.

A estimativa será revisada quando os assets finais forem definidos e testados.
