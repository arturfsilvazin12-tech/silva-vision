# Silva Vision — Estrutura de Release

## Objetivo

Definir como o pacote final será organizado para o usuário.

```text
SILVA-VISION/
├── README.txt
├── INSTALL/
│   ├── INSTALL_PT-BR.txt
│   └── ROLLBACK_PT-BR.txt
├── PRESETS/
│   ├── PERFORMANCE.ini
│   ├── BALANCED.ini
│   └── QUALITY.ini
├── SHADERS/
├── CONFIG/
└── LICENSES/
```

## Regras

O pacote final só recebe componentes validados. Arquivos experimentais ficam separados e identificados.

Nenhum asset de terceiros será incluído sem verificar sua licença.

## Instalação

O instalador final será criado somente depois do primeiro ciclo de testes no PC.
