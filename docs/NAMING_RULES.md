# Silva Vision — Regras de nomes

## Objetivo

Manter o repositório previsível e profissional.

### Pastas

Use nomes em inglês apenas para estruturas técnicas já estabelecidas; documentação pública pode permanecer em PT-BR.

### Arquivos

- `SV_` para componentes próprios;
- versão no formato `V01`, `V02` quando houver evolução incompatível;
- nomes descritivos;
- sem espaços;
- sem nomes aleatórios;
- sem renomear arquivos nativos do jogo sem validação.

### Estados

`experimental`, `dev`, `candidate`, `stable`.
