# Silva Vision — Design System

## Direção

Identidade visual limpa, premium e cinematográfica, inspirada no clima visual de jogos urbanos modernos, mas com identidade própria.

## Regras

- fundo escuro e alto contraste;
- rosa/magenta e dourado apenas como acentos;
- tipografia simples;
- poucos emojis;
- títulos curtos;
- tabelas para informação técnica;
- screenshots e arte como protagonistas;
- sem gradientes excessivos;
- sem aparência de template genérico.

## Tom

Profissional, direto e técnico. O projeto pode ter personalidade, mas não deve parecer uma página de meme.

## Identidade

**SILVA VISION**

Realismo. Atmosfera. Controle.

## Uso de referências

Referências externas servem para estudar iluminação, composição, atmosfera, color grading e apresentação. Não copiamos marcas, logos ou artes proprietárias.
