# 🚀🇧🇷 SILVA VISION — MEGA UPDATE V18

## 🎨 GitHub

O repositório recebeu uma nova camada de organização profissional.

### Criado
- 🐛 template de bug report;
- ✨ template de feature request;
- 🚀 template de Pull Request;
- 📋 checklist de compatibilidade e testes.

## 🧹 Qualidade

Issues agora podem receber informações padronizadas sobre GPU, preset, FPS, cenário e reprodução do problema.

Features passam a exigir objetivo, resultado esperado e possível impacto de performance.

Pull Requests passam a exigir declaração de teste e compatibilidade.

## 🛡️ Segurança

Os templates reforçam que não devem ser enviados assets sem licença, credenciais ou dados pessoais.

## 🎯 Resultado

O GitHub deixa de ser apenas armazenamento de arquivos e passa a ter um fluxo de manutenção: **Issue → desenvolvimento → PR → teste → documentação → release**.
