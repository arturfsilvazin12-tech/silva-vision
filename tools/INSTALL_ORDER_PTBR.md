# 📦🇧🇷 ORDEM DE INSTALAÇÃO — SILVA VISION

> Este documento define a ordem prevista. Não é um instalador automático.

## 1️⃣ Backup

Copiar os arquivos que serão modificados para uma pasta externa.

## 2️⃣ ReShade

Instalar a versão compatível com o GTA V/FiveM usado no computador e apontar os diretórios de shaders corretamente.

## 3️⃣ Core

Carregar primeiro apenas os efeitos essenciais:

1. Exposure
2. Tonemap
3. Color Anchor
4. Local Contrast
5. Sharpen

Bloom deve ser testado separadamente.

## 4️⃣ Preset

Começar pelo **Balanced**. Performance e Quality serão comparados depois.

## 5️⃣ World

Só depois da validação do ReShade começar alterações nativas de World/Citizen.

## 6️⃣ Rollback

Se houver crash, artefato ou degradação inesperada, remover a alteração correspondente e restaurar o backup.

## 🚫 Não fazer

- não misturar vários graphics packs durante o diagnóstico;
- não sobrescrever arquivo nativo sem backup;
- não tratar protótipo como release;
- não apagar arquivos originais para “limpar” instalação.
