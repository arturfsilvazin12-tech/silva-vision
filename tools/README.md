# 🛠️🇧🇷 Ferramentas Silva Vision

## `SV_VALIDATE.ps1`
Verifica a estrutura do projeto sem alterar GTA/FiveM.

## `SV_INSTALL_PLAN.ps1`
Prepara um relatório de instalação e confirma os diretórios esperados. Não instala nada automaticamente.

## Filosofia

As ferramentas são deliberadamente conservadoras enquanto a versão-alvo do FiveM não for validada.
