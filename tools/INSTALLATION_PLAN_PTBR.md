# 📦🇧🇷 Silva Vision — Plano de Instalação

## Antes de instalar

1. Fechar FiveM/GTA V.
2. Fazer backup dos arquivos originais.
3. Guardar o backup fora da pasta do jogo.
4. Instalar ReShade somente quando a versão final do preset estiver validada.

## Estrutura

```text
SilvaVision/
├── shaders/
├── presets/
├── world/
├── performance/
└── tools/
```

## Ordem prevista

1. ReShade + shaders.
2. Preset Balanced.
3. Teste sem World modifications.
4. World/Timecycle somente após confirmar compatibilidade.
5. Citizen/mods por último.

## ↩️ Rollback

Toda alteração nativa deverá possuir backup correspondente antes da instalação.

## ⚠️ Importante

Esta documentação é um plano. O pacote instalável final só será liberado depois de testes reais no ambiente FiveM alvo.
